Files in this folder are Kenney's Furniture Kit GLBs, renamed to fit this app's
category map (seating/table/storage/bed/lighting/decor/rug/other):
  - seating.glb  <- loungeSofa.glb
  - table.glb    <- tableCoffee.glb
  - storage.glb  <- bookcaseOpen.glb
  - bed.glb      <- bedDouble.glb
  - lighting.glb <- lampRoundFloor.glb
  - decor.glb    <- pottedPlant.glb
  - rug.glb      <- rugRectangle.glb
  - other.glb    <- loungeChair.glb
